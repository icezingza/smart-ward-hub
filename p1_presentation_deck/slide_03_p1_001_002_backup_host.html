P1-001 & P1-002: การกู้คืนข้อมูลและความพร้อมของ Host

RESILIENCE & DEPLOYMENT TRUNK
P1-001: SQLite Backup & Restore Baseline
• SQLite Backup API: สตรีมฐานข้อมูลจากเครื่องขณะรัน WAL Mode อย่างถูกต้อง ไม่ใช้วิธี Copy ไฟล์ดิบที่อาจทำให้ WAL ไม่สอดคล้องกัน
• Manifest & Checksum: บันทึก SHA-256 Checksum ตรวจจับการแก้ไขไฟล์สำรอง
• Isolated Restore: กู้คืนข้อมูลบนไดเรกทอรีแยกส่วน พร้อมบังคับคำยืนยันแบบ Fail-Closed
• Secret Hygiene: ปฏิเสธไฟล์ Credential, Key หรือ Token ไม่ให้หลุดเข้าไปใน Backup
P1-002: Host Hardening & Acer Spin N17H2 Auto-Run
• Readiness Validator: สคริปต์ deployment_readiness.py ตรวจค่าเริ่มต้น Pilot, Loopback Binding และ Path Separation
• Windows Auto-Run Template: เตรียม PowerShell/CMD Scripts สำหรับรัน Hub อัตโนมัติเมื่อเปิดเครื่อง Acer Spin N17H2 โดยไม่ Hardcode รหัสผ่าน
การตั้งค่า Fixed Hub ประจำวอร์ดบนเครื่อง Acer Spin N17H2
External Gates Open: ผลการทดสอบระดับซอฟต์แวร์ผ่านครบถ้วน แต่ยังต้องผ่านการทดสอบ Encrypted Backup Storage จริง, Windows Firewall/ACL Hardening จริง และ Power-Loss Drill จริงบนเครื่อง Acer ก่อนเริ่มใช้งานในวอร์ด
