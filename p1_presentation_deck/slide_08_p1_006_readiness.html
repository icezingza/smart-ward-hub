P1-006: Clinical Validation Readiness Preflight

17-GATE PREREQUISITE PROTOCOL
หมวดหมู่เกณฑ์ (Pillar) รายการด่านตรวจที่ต้องผ่าน (17 Prerequisite Gates)
1. Intended Scope • Protocol Version • Intended Use (Decision Support) • Excluded Uses (No Diagnosis/Orders)
2. Governance & Safety • Clinical Owner • Technical Owner • Inclusion/Exclusion Criteria • Privacy Review • Security Review • Clinical Governance Approval
3. Operational Resilience • Consent / Waiver Decision • Data Retention Decision • Training Complete • Stop Conditions • Incident Response • Rollback Plan • Manual Fallback
4. Qualification • Backup/Restore Verified • Device Qualified • Auth/mTLS Validated • HIS Integration Verified • Independent Review Plan • Analysis Plan
สถานะ Preflight Result: คืนเฉพาะ READY_FOR_EXTERNAL_GOVERNANCE_REVIEW หรือ NOT_READY_FOR_CLINICAL_VALIDATION พร้อมล็อกค่า real_world_authorization = False เสมอ
IoT Clinical Telemetry & Governance Validation Topology
Hard Stop Policy: ห้ามเริ่มทดสอบกับผู้ป่วยจริงหากขาด Clinical Governance Sign-off, ขาด Consent/Waiver, มี Raw Identity Leakage, ไม่มี Manual Fallback หรือยังไม่ผ่าน Backup/Restore Drill จริง
