P1-005: การรายงานผลด้วย Non-Accuracy Metrics

WORKFLOW METRICS ONLY
ชื่อเมตริก (Explicit Name) คำนิยามทางเทคนิค ข้อจำกัดและการแปลผล
signal_count จำนวน Signal ที่ระบบ Edge สร้างขึ้น นับเฉพาะในระดับซอฟต์แวร์ ยังไม่ใช่เหตุการณ์จริง
reviewed_count จำนวน Signal ที่ผ่านการ Review แล้ว ต้องมี Reviewer ID และบันทึกเหตุผลกำกับ
review_coverage สัดส่วนการทบทวน (reviewed/total) หากต่ำกว่าเกณฑ์จะตัดสิทธิ์การวิเคราะห์สถิติ
unreviewed_signal_count จำนวนเหตุการณ์ที่ยังค้างการตรวจ ต้องรายงานเสมอ ป้องกันการคัดเลือกเฉพาะข้อมูลดี
confirmed_event_rate_over_reviewed สัดส่วนที่ Reviewer ยืนยันว่าพบเหตุการณ์จริง ไม่ใช่ Sensitivity/PPV เป็นเพียงสัดส่วนบนกลุ่มที่ตรวจ
false_positive_review_rate_over_reviewed สัดส่วนที่ Reviewer ระบุว่าไม่พบเหตุการณ์ ใช้ประเมิน Alarm Burden ไม่ใช่ความแม่นยำรวม
mean_data_freshness_seconds ความล่าช้าเฉลี่ยจาก Sensor ถึง Hub แสดง Network / Buffer Queue Latency
กรอบการกำกับดูแลตัวชี้วัดความปลอดภัยในระบบสารสนเทศสุขภาพ
ข้อห้ามการแปลผล: ตัวเลขจาก Shadow Mode เป็น Workflow & Data Quality Metrics เท่านั้น ห้ามนำไปอ้างอิงเป็นความไว (Sensitivity), ความจำเพาะ (Specificity) หรือประสิทธิภาพในการช่วยชีวิตผู้ป่วย จนกว่าจะมีการออกแบบวิจัยทางคลินิกและอนุมัติโดยคณะกรรมการจริยธรรม
