P1-003: Device Trust & Key Custody Lifecycle

CRYPTOGRAPHIC GOVERNANCE
Provisioning Identity & Public Key Fingerprint
ผูก device_id กับ key_id เฉพาะตัวและ Ed25519 Public Key SHA-256 Fingerprint เริ่มต้นที่สถานะ PROVISIONING
Dual-Control Approval Gate
การเปิดใช้งาน (Activation) บังคับลายมือชื่ออนุมัติจากผู้รับผิดชอบอย่างน้อย 2 คน พร้อมบันทึก Attestation Evidence ID
Key Rotation & Cryptographic Linkage
กุญแจใหม่ต้องเชื่อมโยง previous_key_id และเมื่อกุญแจใหม่เปิดใช้งาน กุญแจเดิมจะถูกเปลี่ยนเป็น SUSPENDED ทันที
Terminal Revocation & Lost Device State
สถานะ REVOKED และ LOST เป็นสถานะสิ้นสุดถาวร ไม่สามารถย้อนกลับมาเปิดใช้งานได้ และการแจ้งอุปกรณ์สูญหายต้องระบุ Incident ID
Private Key Material Exclusion
ระบบปฏิเสธการส่ง Private Key เข้าสู่ Registry และผล Snapshot จะไม่มี Private Key เจือปนโดยสิ้นเชิง
ความต่อเนื่องของการเฝ้าระวังผู้ป่วยคู่ขนานกับวงจรความน่าเชื่อถือของอุปกรณ์
Hardware Attestation Boundary: สัญญาณผ่านการทดสอบใน Software Harness ทั้ง Positive และ Negative Matrix แล้ว แต่การยืนยัน Manufacturer CA, Nordic Secure Element และ Physical Anti-Cloning ยังคงต้องตรวจร่วมกับผู้ผลิตฮาร์ดแวร์จริง
