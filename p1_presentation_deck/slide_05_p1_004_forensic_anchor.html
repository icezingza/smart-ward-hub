P1-004: Forensic Anchor & FileAnchorStore Hardening

IMMUTABILITY & EVIDENCE BASELINE
FileAnchorStore Hardening (Local Anchor)
• Input Validation: ตรวจสอบ package_id, block_hash, chain_tip แบบ Hex64 Canonical Form
• Source-Tree Separation: ปฏิเสธการบันทึกไฟล์ Anchor ไว้ภายในไดเรกทอรีซอร์สโค้ด
• Record Hash & Local Receipt: ออก Structured Receipt พร้อม Record Hash และ Idempotency Key
• Readback Integrity: อ่านย้อนหลังและคัดกรองข้อมูลที่ถูกแก้ไข (Tampered Lines) ออกจากผลตรวจ
External Forensic Anchor Adapter (P1-004 Contract)
• Receipt Identity: ตรวจสอบ Provider ID, Package ID, Block Hash และ Chain Tip ก่อนตอบรับ
• Idempotent Replay: การส่งซ้ำจะไม่สร้าง Anchor ซ้ำในระบบภายนอก
• Append-Only Enforced: ปฏิเสธคำสั่งลบข้อมูล (Delete Forbidden)
• Fault Injection Suite: ปฏิเสธ Mutation Status, Provider Mismatch และ Evidence Mismatch ทั้งหมด
การบันทึกหลักฐานนิติวิทยาศาสตร์ทางการแพทย์ที่โปร่งใสและตรวจสอบได้
Evidence Boundary: Local FileAnchorStore เป็นเพียง Tamper-Evident Adapter ภายใน Edge ไม่ใช่หลักฐานแบบ Tamper-Proof ส่วน External Anchor ยังใช้ Software Stub โดย Independent WORM Server, Trusted Timestamp และ Key Custody จริงยังเป็น External Gates ที่ต้องปิดร่วมกับ รพ.
