ภาพรวม P1 Roadmap: สร้างลำต้นของระบบ

OPERATIONAL TRUNK ROADMAP
Phase 1 (P1-001 ถึง P1-006) ถูกออกแบบขึ้นเพื่อเติมเต็มช่องว่างระหว่าง Software Core (Phase 1–6) กับ Clinical Pilot Deployment โดยเน้นความมั่นคงปลอดภัยของข้อมูล การควบคุมกุญแจ และกรอบธรรมาภิบาลทางคลินิก:
P1-001 Dry-Run Complete
Encrypted Backup & Restore
SQLite Backup API, Manifest Checksum, Isolated Restore และการปฏิเสธไฟล์ Credential ไม่ให้หลุดรอด
P1-002 In Progress
Host Hardening & Deployment
ตัวตรวจ Readiness ตรวจสอบ Loopback Binding, Pilot Defaults และ Windows Script สำหรับ Acer Fixed Hub
P1-003 In Progress
Device Trust Key Custody
Dual-Control Activation, Key Rotation Linkage, Terminal Revocation, Lost Device State และ Private Key Exclusion
P1-004 In Progress
Forensic Anchor Adapters
FileAnchorStore Hardened (Record Hash, Readback) + External WORM Adapter Contract พร้อม Receipt Verification
P1-005 In Progress
Clinical Shadow-Mode
Zero-PII Token Boundary, Safe Non-Diagnostic Labels, Stop/Resume Controls และ Non-Accuracy Metrics
P1-006 In Progress
Clinical Validation Readiness
17-Gate Preflight Validator ตรวจสอบความพร้อมของ Protocol, Owner, Safety และ Privacy ก่อนขออนุมัติคลินิกจริง
หลักการสำคัญ: ทุกงานใน P1 มีผลการทดสอบเชิงประจักษ์ (Deterministic Tests) รองรับในระดับซอฟต์แวร์ แต่การปิด Gate สู่ Production ยังต้องอาศัยการทดสอบร่วมกับระบบภายนอกและบุคลากรทางการแพทย์จริง
