Architecture & Control Plane: Fixed Hub เป็น Authority

TIERED ZERO-TRUST MAP
Fixed Hub (Acer Spin N17H2 Candidate) — Core Authority
ทำหน้าที่เป็น Single Authority ประจำวอร์ด รัน SQLite WAL Mode, RAM Ring Buffer, AI Triage, Hash Chain กล่องดำ และ Endpoint ควบคุมเตียง การสตรีมสัญญาณชีพจากทุกสายรัดจะจบที่เครื่องนี้เพื่อความเสถียรสูงสุด
Outside-in Admission Console
จุดสแกนและลงทะเบียนภายนอกวอร์ด แปลงรหัสบาร์โค้ด HN ให้กลายเป็น patient_token และตรวจเช็กเตียงว่างแบบเรียลไทม์ ป้องกันไม่ให้บุคลากรต้องเดินเข้าพื้นที่เสี่ยงเพื่อจองเตียง
Roaming Tablet Client (BMAX i11_s Candidate)
แผงควบคุมแบบถือเดินตรวจ (Ward Round) ดึง Snapshot ล่าสุดและส่งคำสั่งผ่าน Hub เท่านั้น ไม่มีสิทธิ์สั่ง Purge หรือตัดสินใจเองหากตัดการเชื่อมต่อจาก Fixed Hub
Zero-Trust Trust Boundaries: แยกโซนเครือข่ายชัดเจนระหว่าง IoT Sensors (Untrusted/Attested) ➡️ Hub Ingestion (Enforced Ed25519) ➡️ SQLite WAL (Local Truth) ➡️ HIS Gateway (mTLS/OIDC).

Adapter Extensibility
