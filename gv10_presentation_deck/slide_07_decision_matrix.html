Evaluation Criteria // Independent Review Decision Rules

Evidence Decision Matrix ของคณะกรรมการอิสระ

เกณฑ์การตัดสิน Review Outcome สำหรับหลักฐานแต่ละประเภทและผลกระทบต่อสถานะของ External Gates

Evidence Class / Condition Expected Review Outcome Gate Status Implication
SOFTWARE_VERIFIED ACCEPTED_FOR_REVIEW
หาก Hash, Provenance และ Redaction ผ่าน		 รับเข้าสู่การตรวจซ้ำระดับโค้ด; ไม่ปิด External Gate โดยอัตโนมัติ
SIMULATION_ONLY ACCEPTED_FOR_REVIEW
ติดป้ายกำกับ Simulation ชัดเจน		 บันทึกพฤติกรรมภายใต้แรงกดดันจำลอง; ไม่เทียบเท่า Hardware/Field Evidence
EXTERNAL_UNVERIFIED REQUIRES_CLARIFICATION / BLOCKED Gate ยังคงสถานะ OPEN หรือ BLOCKED จนกว่าจะได้รับ Transcript จากระบบภายนอกจริง
CLINICAL_GOVERNANCE_UNVERIFIED BLOCKED_EXTERNAL_EVIDENCE Gate ด้าน Clinical BLOCKED ทันที จนกว่าจะมีลายเซ็นรับรองจาก Clinical Owner
BLOCKER_RECORD ACCEPTED_FOR_REVIEW
รับเพื่อเป็นหลักฐานอธิบายข้อจำกัด		 Gate คงสถานะ BLOCKED ไว้อย่างเปิดเผย พร้อมระบุ Prerequisite ที่ต้องแก้ไข
Raw ID / Bad Hash / Forbidden Claim REJECTED_FAIL_CLOSED สกัดกั้นทันที; ห้ามบันทึกเข้า Dossier Bundle เพื่อป้องกันข้อมูลเท็จและข้อมูลหลุด
หัวใจของ Decision Matrix: การประเมินแบ่งแยกชัดเจนระหว่าง "หลักฐานยืนยันความสมบูรณ์ของซอฟต์แวร์ (Software Verified)" กับ "การปิดเกตสภาพแวดล้อมจริง (Gate Passed)" ป้องกันข้ออ้าง Clinical Validation ก่อนได้รับความเห็นชอบจากคณะกรรมการ
